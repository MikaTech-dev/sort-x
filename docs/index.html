How It Works

Three easy steps to rank any followers or following list

01

Open X Profile

Go to any user profile on X (Twitter) and click into their Followers or Following tab.

02

Auto-Scroll

Click the ⬇ button to auto-scroll down the list and fetch user data into memory.

03

Rank & Sort

Click Sort to view the interactive ranked modal sorted instantly by follower count.

Privacy Policy

100% client-side execution — zero remote data storage

I believe, your data is yours alone. That's why i built this extension with a strictly client-side, in-memory architecture. I do not run any remote servers, nor do I collect, transmit, or store any of your profile information, followers, or activity.

When you auto-scroll to fetch users, their information is held only in your browser's temporary memory. The moment you close or refresh the tab, that data is instantly wiped. There are zero tracking pixels, cookies, or telemetry scripts embedded in my code. Don't just take my word for it, my codebase is 100% open source, so you can freely audit my source code to verify my privacy commitment. Sort-X does not manipulate anything except the dom to display the ranked list.

Installation Instructions

Install manually on any Chromium browser for free

1

Download Latest Release

Download sort-x-chromium-vX.X.X.zip from GitHub Releases or Codeberg Releases and extract the zip file on your computer.

2

Open Extensions Page

In your browser address bar, enter chrome://extensions (or edge://extensions / brave://extensions).

3

Enable Developer Mode

Toggle the Developer mode switch in the upper right corner of the Extensions page.

4

Load Unpacked Extension

Click the Load unpacked button and select the unzipped extension directory.
